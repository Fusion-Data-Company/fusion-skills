The processor needs an operator-configured scheduler; none is activated here.

Webhook body requires request_id UUID and notes string. Sign exact raw UTF-8 body with HMAC SHA256(secret, timestampSeconds + '.' + body), headers x-fusion-timestamp and x-fusion-signature. Timestamp tolerance 300 seconds. Retry same request ID and exact bytes, with refreshed timestamp/signature. Different bytes under same ID return409. Output is rule-based score, route recommendation and response_draft; it is not an LLM judgment, actual booking, SMS/email send or voice call. CRM payload event lead.review_ready includes stable event_id/Idempotency-Key. Receiver must deduplicate and enforce consent before any customer outreach.

CRM HTTP2xx records delivered-to-CRM only. Non2xx -> needs_review. Timeout/network/crashed lease -> uncertain. No automatic uncertain retry. Admin POST /api/deliver with action review, jobId, decision confirmed_delivered or confirmed_not_delivered, and nonempty evidence (minimum20 characters) saves a review record. Confirmed absence permits next processor run to retry same stable event ID. Evidence quality and actual receiver status remain operator responsibilities.
